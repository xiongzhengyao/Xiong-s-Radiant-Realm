# 惯性传感器在手机中的应用

手机里的 IMU（加速度计 + 陀螺仪，常配磁力计）支撑屏幕旋转、计步、相机防抖辅助、游戏体感与 AR 姿态。对驱动与算法工程师来说，难点通常不在「读出原始数据」，而在标定、坐标系统一、功耗与融合稳定性。

## 背景

惯性器件输出的是相对物理世界的运动观测量：

- 加速度计：比力（含重力）
- 陀螺仪：角速度
- 磁力计：地磁场向量（易受软硬磁干扰）

手机场景的特殊约束：

- 尺寸与功耗严格
- 扬声器、磁铁、无线充电导致磁场畸变
- 相机/显示等高负载时总线与中断开销需可控
- 应用侧期望「开箱即用」的姿态与活动识别

## 常见惯性传感器

### 加速度计

- **测量线性加速度**（含重力分量）
- **重力感应**：静止时模长约 1g，可估倾角
- **姿态检测**：与陀螺融合后得到更稳的 pitch/roll

关注量程（±2g/±4g/±8g/±16g）、噪声密度、ODR（输出数据率）与 FIFO 深度。

### 陀螺仪

- **角速度测量**（deg/s 或 rad/s）
- **旋转检测**：短时姿态积分的主力
- **游戏控制 / 防抖辅助**：高 ODR 与低延迟更重要

陀螺有零偏（bias）与温漂；上电后短时静止标定、运行时偏置跟踪是常规手段。

### 磁力计

- **方向感应 / 电子罗盘**
- **磁场强度**：可用于硬磁干扰检测
- **航向角 yaw**：单靠加计+陀螺难以长期稳定

磁力计必须配合软硬磁校准；否则罗盘会在特定方位「卡住」或绕圈漂移。

| 器件 | 主要物理量 | 典型问题 |
| --- | --- | --- |
| 加速度计 | ax, ay, az | 振动噪声、安装倾斜 |
| 陀螺仪 | gx, gy, gz | 零偏、积分漂移 |
| 磁力计 | mx, my, mz | 软硬磁、本地磁场变化 |

## 坐标系统一

驱动与 HAL 层应尽早把芯片坐标变换到**设备坐标系**（Android 等平台有明确定义）：

```text
芯片轴 → 安装矩阵(R) → 设备轴 →（可选）世界系融合
```

建议在板级配置（Device Tree / 板级文件）中固化安装矩阵与轴向翻转，而不是在多个算法模块各自「猜方向」。

## 驱动开发

典型软件栈分层：

1. **数据采集**：I2C/SPI + 中断/FIFO；批量读降低总线占用
2. **数据融合**：互补滤波 / Madgwick / Mahony / EKF 等
3. **姿态算法**：四元数或旋转矩阵；注意万向节锁
4. **电源管理**：按场景切换 ODR、批量模式、唤醒中断

### 采集与中断

```text
配置 ODR / 量程 / LPF
→ 使能 data-ready 或 FIFO watermark IRQ
→ IRQ 中批量读取
→ 时间戳对齐（尽量用硬件时间戳或同一时钟域）
→ 上报传感器框架 / 用户态
```

伪代码示例（概念）：

```c
/* 读加速度计 6 字节：X/Y/Z 各 16-bit */
int imu_read_accel(int fd, int16_t out[3]) {
    uint8_t reg = ACCEL_OUT_X_L;
    uint8_t buf[6];
    if (i2c_write_read(fd, &reg, 1, buf, 6) < 0)
        return -1;
    out[0] = (int16_t)(buf[1] << 8 | buf[0]);
    out[1] = (int16_t)(buf[3] << 8 | buf[2]);
    out[2] = (int16_t)(buf[5] << 8 | buf[4]);
    return 0;
}
```

### 融合要点

- 加计给出倾角参考，抑制陀螺倾角漂移
- 磁力计约束航向，但要可降权（检测到磁场异常时）
- 相机 EIS/OIS 路径对延迟敏感：融合输出应给出明确时间戳

简单互补滤波示意：

```text
angle = α * (angle + gyro * dt) + (1 - α) * acc_angle
```

生产环境更多使用带偏置状态的滤波，并按温度分段补偿。

## 应用场景

- **屏幕旋转**：加计为主，结合迟滞避免抖动翻转
- **计步器**：加速度模长峰谷检测 + 步伐长度估计；注意口袋/手持差异
- **VR/AR**：低延迟高 ODR，陀螺权重高；磁力与视觉定位常作绝对参考
- **游戏控制**：体感操作依赖稳定姿态与可预测延迟
- **相机辅助**：防抖、水平仪、运动检测触发；与帧时间戳对齐是关键

## 标定与调试

| 项目 | 做法 |
| --- | --- |
| 加计零偏/灵敏度 | 六面标定或工厂夹具 |
| 陀螺零偏 | 静止平均；温补表 |
| 磁力计 | 8 字校准 / 椭球拟合 |
| 安装误差 | 与整机坐标系对齐矩阵 |
| 噪声 | 看功率谱；区分结构振动与电气噪声 |

调试清单：

1. 静止时加计模长是否接近 1g
2. 陀螺静止输出是否接近 0（或已知偏置）
3. 旋转 90° 后轴映射是否符合设备坐标
4. FIFO overrun / IRQ 丢失是否导致时间戳跳跃
5. 低功耗模式切换后首样本是否需要丢弃（warm-up）

## 总结

加速度计、陀螺仪、磁力计分工明确：短时靠陀螺，倾角靠加计，航向靠磁力（并随时准备降权）。手机 IMU 工程的核心是**坐标系统一、标定可追踪、采集带时间戳、融合可降级**。把驱动、HAL 与算法的边界划清，才能在旋转、计步、游戏与 AR 等场景里给出稳定体验。
